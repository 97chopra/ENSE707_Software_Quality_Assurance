# Submission Checklist

- [ ] Baseline build and test context recorded.
- [ ] `Week6CycleAddendum.md` completed.
- [ ] Two detailed GitHub Issues created, or two issue templates completed if GitHub was unavailable.
- [ ] Severity and priority justified separately.
- [ ] `Week6ProgressReport.md` contains formulas, denominators and interpretations.
- [ ] Control actions include their trade-offs.
- [ ] Fixed-build confirmation and regression evidence evaluated.
- [ ] Issue status updated using evidence rather than developer assertion alone.
- [ ] `Week6CompletionReport.md` states untested and blocked scope.
- [ ] Residual risks have mitigations, owners and follow-up actions.
- [ ] Copilot-generated content was checked and unsupported claims were corrected.
- [ ] Work committed to the `week6-test-management` branch.
